# Sistema GVL - Projeto Integrador (Etapa 9)

Repositório oficial da aplicação desenvolvida para o Módulo de Gestão e Cadastro de Produtos do **Sistema GVL**, integrando uma API REST em Java Spring Boot com uma interface Web front-end.

## Tecnologias Utilizadas
* **Back-end:** Java Spring Boot (Spring REST API), Maven, Apache NetBeans IDE.
* **Front-end:** HTML5, CSS3, JavaScript (Fetch API).
* **Versionamento:** Git e GitHub.

## Funcionalidades
* Cadastro assíncrono de produtos via interface web comunicando diretamente com o servidor Java.
* Validação de formulários e tratamento de requisições HTTP REST.
* Geração dinâmica de identificadores de registo (ID).

## Como Executar o Projeto
1. Clone este repositório ou descarregue os arquivos.
2. Abra o projeto back-end no NetBeans e execute a classe principal `SistemagvlWebApplication` (porta 8080).
3. Abra o ficheiro `index.html` (front-end) no seu navegador para interagir com o sistema.
